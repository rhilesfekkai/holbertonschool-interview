# Star Wars Characters

A JavaScript script that prints all characters
from a Star Wars movie using the Star Wars API.

## Usage

./0-starwars_characters.js 3

## Requirements

- Node.js
- request module
- Star Wars API

## Implementation

1. Retrieve the movie information.
2. Read the characters array.
3. Retrieve each character sequentially.
4. Print each character name in API order.
